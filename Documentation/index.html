Introduction

Solace Interiors is a clean, editorial-style HTML template built for interior design studios, architecture firms and civil engineering practices. It ships with 7 ready pages covering a homepage, portfolio, gallery, services, about, contact and a cost-calculator page, plus a documentation set to help you customize it quickly.

Getting Started

Opening the template

No build step is required to preview the site. Open any file inside HTML/ directly in a browser, or serve the folder with any static server (Live Server, python3 -m http.server, etc.).

Editing text

All copy lives directly in the HTML — open the relevant page in a code editor and edit the text between tags. There is no CMS or templating layer.

Replacing images

Images in the live preview are pulled from an external demo CDN for preview purposes only and are not included in the download package (see Image Credits). Replace every <img src="..."> with your own licensed photography, keeping the same aspect ratio where possible.

Changing the logo

The logo used in the mobile menu is at assets/img/logo/logo-white.png. Swap this file with your own (transparent PNG or SVG recommended, roughly square). The text wordmark in the header/footer is plain HTML text — edit it directly.

Changing colors

Brand colors are defined as Tailwind design tokens in src/input.css:

@theme {
  --color-clifford: #da373d;
  --font-secondary: "Manrope", sans-serif;
  --font-primary: "Hedvig Letters Serif", serif;
  --text-csm: 16px;
}

Most of the palette (blacks, creams, browns) is applied with Tailwind arbitrary values directly in the HTML (e.g. bg-[#5d5346]) rather than tokens — use find & replace across the HTML/ folder to re-theme quickly.

Changing fonts

Fonts are loaded from Google Fonts in the <head> of every page. Swap the <link> tags and update --font-primary / --font-secondary in src/input.css, then rebuild (see Tailwind CSS).

Editing navigation & footer

The main nav, mobile menu and footer markup is repeated at the top/bottom of every page (this is a static HTML template, not a component system). Edit each page individually, or use your editor's multi-file find & replace.

Adding / removing sections

Each page is divided into clearly commented <section> blocks. Duplicate a section block to repeat it, or delete the whole <section>…</section> to remove it.

Tailwind CSS

This template uses Tailwind CSS v4, compiled ahead of time into a static file — you do not need Node.js just to view or deploy the template. The compiled tailwind.css is already included in HTML/assets/css/.

Node is only needed if you want to change design tokens (colors, fonts) or add new utility classes:

Requirements

Node.js 18+ and npm.

Installation

npm install

Development (watch mode)

npm run dev

Production build

npm run build

Both commands read src/input.css and write the compiled file to HTML/assets/css/tailwind.css.

JavaScript Structure

JavaScript is written directly inside each page in <script> blocks near the closing </body> tag, grouped by feature (mobile menu, nav blur-on-scroll, Swiper sliders, GSAP scroll animations, cost calculator logic, contact form validation). No console errors or debug statements are present in the shipped code.

Third-party libraries are loaded via CDN <script> tags in the <head>/before </body> — see Plugins & Libraries.

Forms

The Contact and Cost Calculator pages include front-end forms with client-side validation (required fields, basic email/phone checks) implemented in vanilla JavaScript.

No backend is included. Submitting a form currently only shows a client-side "thank you" confirmation — it does not send an email or store data anywhere. To make the forms functional, connect the existing fetch() call (or add one) to a backend of your choice:
  • A simple PHP mail script
  • A Node.js / Express endpoint
  • Formspree
  • Web3Forms
  • Your own API

Support Notes

This is an HTML/CSS/JS template. Basic working knowledge of HTML, CSS and JavaScript is recommended to customize it beyond text and image swaps (e.g. re-theming colors, editing animations, wiring up a form backend).
