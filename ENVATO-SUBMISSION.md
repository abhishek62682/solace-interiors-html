# Solace Interiors — ThemeForest Submission Package

## Product Title
Solace Interiors – Interior Design & Architecture HTML Template

## Short Description
Solace Interiors is a clean, editorial-style HTML template built for interior design studios, architecture firms and civil engineering practices. It combines a calm, gallery-like visual language with a fully responsive, production-ready codebase — including a built-in project cost calculator.

## Main Description

**Overview**
Solace Interiors is a 7-page HTML template designed for interior design, architecture and civil engineering businesses that want a refined, editorial presentation of their work. The layout favors large imagery, generous whitespace and serif/sans-serif typographic contrast to give a premium, studio-like feel.

**Best Use Cases**
- Interior design studios
- Architecture firms
- Civil engineering / turnkey construction businesses
- Furniture & space-planning consultancies
- Portfolio sites for solo designers

**Key Features**
- 7 fully built, ready-to-use pages
- Interactive project cost calculator (front-end)
- Swiper-powered testimonial and image sliders
- Scroll-based reveal animations (GSAP + ScrollTrigger + SplitText)
- Sticky navigation with blur-on-scroll effect
- Fully responsive from 375px mobile up to large desktop
- Clean, semantic HTML5 markup
- Production-compiled Tailwind CSS — no build tools required to deploy
- Well-documented, easy-to-customize codebase

**Included Pages**
1. Home
2. About
3. Services
4. Portfolio
5. Gallery
6. Cost Calculator
7. Contact

**Responsive Design**
Tested and adjusted at 375px, 430px, 768px, 1024px, 1440px and large-desktop breakpoints. No horizontal overflow, broken grids or unreadable text at any size.

**Technology Used**
- HTML5
- Tailwind CSS v4 (compiled to static CSS)
- Vanilla JavaScript
- Swiper.js (sliders)
- GSAP, ScrollTrigger, SplitText (animations)
- Remix Icon (icon font)

**Customization**
Every page is plain HTML — no templating engine or build step required to edit text, swap images, or rewire navigation. A Tailwind source file is included for buyers who want to change design tokens (colors/fonts) and rebuild.

**Browser Compatibility**
Latest versions of Chrome, Firefox, Safari and Edge.

**Documentation**
Full setup and customization documentation is included at `Documentation/index.html`.

**Credits**
See `Documentation/index.html` → Fonts, Icons, Plugins & Libraries, and Image Credits sections for a full breakdown of third-party resources and their licenses.
