SUPPORT & CUSTOMIZATION:
  This is a static HTML/CSS/JS template. Basic knowledge of HTML,
  CSS and JavaScript is recommended for customization beyond
  simple text/image swaps. Full instructions — including how to
  edit colors, fonts, images, navigation and forms — are in
  Documentation/index.html.

  The contact and cost-calculator forms are front-end only and are
  not connected to a backend. See the Documentation "Forms" section
  for instructions on connecting them to PHP, Node.js, Formspree,
  Web3Forms, or your own API.
